Five ways to read a nominal.

The taxonomy describes how the English noun functions in the sentence pair, not whether the word is grammatically a noun in isolation.

1. Direct verbalization

Definition
The English nominal names an action, change, or result, and the Chinese rendering expresses that action directly as a verb or verbal phrase.
Theory source
Vinay and Darbelnet’s transposition, especially noun-to-verb shift; the broader nominalization–verbalization contrast described by Halliday.
Decision rule
Choose this when the English lemma has a transparent action meaning and the Chinese rendering can function as the predicate or verbal head without a separate light verb.
Positive example
protection → 保护; destruction → 毁灭.
Negative example
discussion → 讨论. It names a social activity, but the category is better treated as a communicative event.
Boundary case
action → 开拍. It is action-like, but the rendering is a production command tied to a film set, so it is coded as event/process.

2. Event / process

Definition
The nominal names an event, procedure, institutional process, or bounded happening rather than a single transferable action.
Theory source
Vinay and Darbelnet on modulation and transposition; event-oriented analysis of translated dialogue.
Decision rule
Choose this when the Chinese rendering describes how an event unfolds or is administered: a ritual, procedure, conflict, sanction, or organized activity.
Positive example
celebration → 庆祝; interrogation → 审讯.
Negative example
construction → 建造. It is a bounded process, but the supplied pair presents a direct noun-to-verb correspondence, so it is coded as direct verbalization.
Boundary case
confession → 招供 / 忏悔. Religious confession can be a ritual (event), but the individual speech act is also prominent; it is coded as event because the sample emphasizes the institutional procedure.

3. Speech / communication

Definition
The nominal names a communicative act, its content, or a relationship managed through language.
Theory source
Austin and Searle’s speech-act theory; translation as re-performing an utterance in context.
Decision rule
Choose this when the noun can be paraphrased as “saying / asking / telling / promising / warning” in the sentence, or when its Chinese rendering is a speech verb.
Positive example
question → 问; explanation → 解释.
Negative example
attention → 注意. It directs notice, but does not report a proposition; it is coded as mental/emotional.
Boundary case
permission → 允许. Permission can be an institutional relation, but in the pairs here it is enacted by granting or asking; it is coded as speech/communication.

4. Mental / emotional

Definition
The nominal names an internal state, perception, attitude, desire, or emotional response.
Theory source
Cognitive and affective dimensions of translation shifts; semantic modulation in Vinay and Darbelnet.
Decision rule
Choose this when the Chinese rendering primarily reports what a person notices, feels, wants, remembers, or evaluates.
Positive example
obsession → 痴迷; disappointment → 失望.
Negative example
attention → 稍息. The English noun is internal, but this pair is a command, not a report of cognition.
Boundary case
attention → 注意. Most occurrences are coded mental/emotional because the rendering directs or gives notice. Attention! → 稍息 is a contextual exception retained in the same lemma-level class.

5. Relational / state

Definition
The nominal names a condition, role, entitlement, availability, or relationship rather than an action or a communicative event.
Theory source
Halliday’s ideational meaning and relational processes; descriptive translation studies on shifts in participant roles.
Decision rule
Choose this when the rendering expresses being in a condition, having a status, or standing in a relation. These records often contain stative verbs or predicative expressions.
Positive example
presence → 出现; exception → 例外.
Negative example
reservation → 预订. Booking is an action, so it belongs to direct verbalization.
Boundary case
position → 担任 / 排版. Both renderings are context-specific; the class records their predicative, role-oriented function rather than a single lexical meaning.

General rules and revision log

Unit of classification. Categories are assigned to the English nominal lemma type, not separately to each occurrence. This is a deliberate consistency choice and a limitation: attention → 稍息 remains in the mental/emotional class even though that one occurrence is a command.

Tie-breaking. If a record could fit two categories, the deciding question is what the Chinese rendering does in this sentence pair, not what the English noun means in a dictionary.

Revision 1. The initial draft used only direct action versus communication. It was too coarse and merged events, speech, and states.

Revision 2. I added mental/emotional and relational/state after testing examples such as obsession, disappointment, and presence.

Revision 3. A build-time check found 13 observed lemmas missing from my first exhaustive map. I corrected the assignments and made the build fail on any unmapped or extra term rather than silently defaulting.

Reliability note. The full 195-lemma map is in scripts/build_corpus.py. A second coder should reclassify a random sample and report agreement before treating these categories as reliable. No inter-annotator agreement has yet been computed.

1. 直接動詞化

定義
英文名詞表示動作、變化或結果，中文譯法以動詞或動詞短語直接表達該動作。
理論來源
Vinay 與 Darbelnet 的「詞性轉換」，特別是名詞轉動詞；亦參考 Halliday 關於名詞化與動詞化的討論。
判定規則
若英文詞元有清楚動作義，而中文譯法可獨立充當謂語，選此類。
正例
protection → 保護；destruction → 毀滅。
反例
discussion → 討論：雖涉及行動，但更適合歸為溝通事件。
邊界個案
action → 開拍：具動作性，但屬片場製作口令，因此歸入事件／過程。

2. 事件／過程

定義
英文名詞表示事件、程序、制度性過程或有界限的發生，而非單一可轉移動作。
理論來源
Vinay 與 Darbelnet 的「調節」及「詞性轉換」；翻譯對白中的事件導向分析。
判定規則
若中文譯法描述事件如何展開或被執行，例如儀式、程序、衝突、制裁或組織活動，選此類。
正例
celebration → 慶祝；interrogation → 審訊。
反例
construction → 建造：屬有界限過程，但提供的句對呈直接名詞—動詞對應，因此歸入直接動詞化。
邊界個案
confession → 招供／懺悔：宗教告解是儀式，同時亦是言語行為；本樣本以制度程序為主，故歸入事件。

3. 言語／溝通

定義
英文名詞表示言語行為、其內容，或透過語言維持的關係。
理論來源
Austin 與 Searle 的言語行為理論；在情境中重新執行話語的翻譯觀。
判定規則
若名詞在句中可改寫成「說／問／告訴／承諾／警告」等，或中文譯法為言語動詞，選此類。
正例
question → 問；explanation → 解釋。
反例
attention → 注意：雖要求注意，但不陳述命題；歸入心理／情感。
邊界個案
permission → 允許：可視為制度關係，但句對中由授予或許可的行為體現，故歸入言語／溝通。

4. 心理／情感

定義
英文名詞表示內在狀態、感知、態度、欲望或情緒反應。
理論來源
翻譯轉換中的認知與情感面向；Vinay 與 Darbelnet 的語義調節。
判定規則
若中文譯法主要報告某人注意、感受、想要、記得或評價甚麼，選此類。
正例
obsession → 痴迷；disappointment → 失望。
反例
attention → 稍息：英文詞表示內在注意，但這句是命令，不是認知報告。
邊界個案
attention → 注意：大部分出現屬心理／情感，因為譯法要求或給予注意；Attention! → 稍息作為同詞元的語境例外保留。

5. 關係／狀態

定義
英文名詞表示條件、角色、權利、可用性或關係，而非行動或溝通事件。
理論來源
Halliday 的經驗意義及關係過程；描述翻譯研究中的參與者角色轉換。
判定規則
若譯法表達處於某種條件、擁有某種地位或某種關係，選此類；記錄多含狀態動詞或謂語表達。
正例
presence → 出現；exception → 例外。
反例
reservation → 預訂：預訂是行動，故歸入直接動詞化。
邊界個案
position → 擔任／排版：兩者皆依情境而定，本類記錄其謂語性及角色導向功能，而非單一詞義。

一般規則與修訂記錄

分類單位。類別按英文名詞詞元而非逐次出現分配。這是為保持一致性的選擇，也是一項限制：attention → 稍息仍留在心理／情感類，儘管該次出現其實是命令。

平手規則。若一筆記錄可能屬兩類，決定因素是中文譯法在這個句對中「做甚麼」，而不是英文名詞在詞典中的意思。

修訂一。初稿只區分直接動作與溝通，範圍過粗，混淆了事件、言語及狀態。

修訂二。測試 obsession、disappointment、presence 等例子後，加入心理／情感及關係／狀態。

修訂三。建立資料時發現 13 個實際詞元未列入初版映射。我更正分類，並令程式在任何未映射或額外詞元出現時停止，而不靜默使用預設值。
