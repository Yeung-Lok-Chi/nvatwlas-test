What this sample can—and cannot—show.

A curated, not random, view. The 500 supplied IDs are not reproducible from a stated NV Atlas random seed. Treat this as a frozen analytical sample, not a prevalence estimate for the whole corpus.

A checking queue is not a human check. The fixed 50-row sample has been reconciled against the public record set programmatically. A person should still read and approve it before marking it human_checked.

Category judgments are interpretive. The five categories summarize the noun's function in context. Boundary cases are documented openly in the codebook.
